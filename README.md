## 💡 About

This repository contains **46 Python programs** organized across **5 college assignments** and a dedicated **Lab Questions** section. Each program is self-contained and designed to reinforce fundamental programming concepts — from basic arithmetic to data visualization.

> Perfect for anyone preparing for **lab exams**, **viva voce**, or just practicing Python.

## 🚀 Getting Started

### Prerequisites

- **Python 3.x** — [Download here](https://www.python.org/downloads/)
- **matplotlib** *(only needed for `election_pie_chart.py` and `plot_complexity.py`)*
  ```bash
  pip install matplotlib
  ```

### Clone & Run

```bash
git clone https://github.com/Arnab-apk/python_linux.git
cd python_linux
```

Run any program:

```bash
python college_python/Assignment1/prog1.py
python Lab_Questions/prime_check.py
```
